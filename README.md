# 4-Bit Transistor CPU

> 🚧 **Work in Progress** — This project is currently under active development.

A custom 4-bit processor designed and simulated from scratch using Resistor-Transistor Logic (RTL) in Logisim.

## Planned Features
* **4-bit ALU & Registers:** Basic arithmetic, logic, and data storage.
* **Transistor Logic:** Built using discrete RTL principles.
* **Simulation:** Designed and tested in Logisim.
